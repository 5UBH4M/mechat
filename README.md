# MeChat 💬

MeChat is a modern one-to-one messaging application designed to provide a fast, secure, and seamless communication experience. Built with a clean and intuitive user interface, MeChat enables users to connect, chat in real time, share media, and stay connected anytime, anywhere.

## ✨ Features

### 💬 Real-Time Messaging
- Instant one-to-one chat
- Real-time message delivery
- Online and offline status indicators
- Message timestamps

### 👤 User Management
- User registration and login
- Secure authentication
- User profile customization
- Profile picture support

### 📨 Chat Experience
- Send and receive text messages
- Emoji support
- Message read receipts
- Typing indicators
- Conversation history

### 📎 Media Sharing
- Share images
- Share documents
- Preview media before sending
- Download shared files

### 🔔 Notifications
- Push notifications for new messages
- In-app notifications
- Unread message indicators

### 🎨 Modern UI
- Clean and responsive design
- Material Design inspired interface
- Dark Mode support
- Smooth animations and transitions

### 🔒 Security
- Secure user authentication
- Protected user data
- Encrypted communication
- Privacy-focused architecture

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK
- Node.js
- MongoDB
- Git

---

### Clone the Repository

```bash
git clone https://github.com/5UBH4M/mechat.git
```

```bash
cd mechat
```
---

### Project Setup

Navigate to the Flutter project:

```bash
cd client
```

Install Flutter dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
